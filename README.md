# Лут-планировщик

Аналитика рынка оффлайн-трейда [blizzless.trade](https://blizzless.trade) по общедоступным данным: честные цены валют,
курсы покупки и продажи, недооценённые объявления и маршрут обменов из своего тайника к любой цели
(руна, ключ, шард, вещь).

> **Неофициальный проект.** Не является официальным ресурсом Blizzless или Blizzard Entertainment, не связан с ними,
> не одобрен и не поддерживается ими. Проект не вносит изменений в данные и не вызывает операций на торговой площадке:
> не создаёт объявлений, не делает предложений, не покупает и не продаёт. Он только читает общедоступные объявления
> и, по запросу игрока, его собственный тайник. Diablo, Blizzard и Blizzard Entertainment — товарные знаки
> Blizzard Entertainment, Inc.; Blizzless и blizzless.trade принадлежат их владельцам. Проект не присваивает эти
> товарные знаки и интеллектуальную собственность; названия игровых предметов упоминаются только для обозначения.

Один образ: статический Go-бинарь отдаёт API под `/api` и встроенный в него фронтенд под `/`.
Вся логика на бэкенде, фронтенд только запрашивает данные и рисует их. Сторонних зависимостей нет.

Прод: https://loot-planer.nic-weiss.tech

## Команды

```bash
make help       # все команды
make dev        # без Docker: http://localhost:8765, фронт читается с диска, автообновление рынка выключено
make test       # go vet + go test
make start      # локально через compose.yaml: http://localhost:8000 (stop, logs)
make build      # образ harbor.nic-weiss.tech/d2_bt_analytics/app:<VERSION> и :latest
make publish    # docker push в Harbor
make deploy     # на myvps: /root/projects/d2_bt_analytics, контейнер prod_d2_bt_analytics
make release    # test + build + publish + deploy
```

Версия лежит в файле `VERSION`; перед выкладкой новой версии подними её. Переопределить можно так:
`make build VERSION=2.0.1`.

## Деплой

`make deploy` копирует на сервер `deploy/docker-compose.yml` и `deploy/Makefile` и запускает там `make update`.
Команда скачивает образ, пересоздаёт только сервис `app` в compose-проекте `d2_bt_analytics` и ждёт статуса healthy.
Другие контейнеры сервера она не трогает. На сервере:

- данные лежат в `data/`;
- настройки задаются в `.env` (`COOKIE_SECURE=true`);
- приложение слушает `127.0.0.1:8190`;
- nginx проксирует на этот порт: `deploy/nginx/loot-planer.conf`, сертификат выпускает и продлевает certbot;
- для управления там есть `make ps`, `make log`, `make stop` и `make start`.

Бинарь собирается под `GOAMD64=v1`: процессор VPS не поддерживает x86-64-v2.

При первом старте снимка рынка ещё нет, и сервис сам скачивает объявления с сайта. Это 3–10 минут, страница
покажет ожидание и обновится сама. Дальше рынок обновляется по расписанию, а админ может обновить его вручную кнопкой «Обновить маркет».

Памяти нужно 20–55 МБ в покое и до ~90 МБ во время обновления с сайта (замер на проде). Объявления читаются из JSON потоком, и
сохраняются только нужные поля: снимок занимает ~16 МБ вместо ~100.

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `8000` | порт HTTP |
| `DATA_DIR` | `/data` (в образе) | снимок рынка (`market/`) и сессии (`sessions/`) |
| `MARKET_REFRESH_HOURS` | `6` | период автообновления рынка, `0` — только вручную |
| `MARKET_REFRESH_COOLDOWN_MINUTES` | `10` | ручное обновление не чаще этого |
| `SEASON_START` | — | начало ладдер-сезона `ГГГГ-ММ-ДД`; без неё определяется по объявлениям (первый день после затишья) |
| `RELEVANCE_PACE_DAYS` | `7` | кривая актуальности: до какого дня сезона цены быстро сползают |
| `RELEVANCE_FADE_DAYS` | `45` | кривая актуальности: как быстро стареют сделки, `0` — внутри сезона все равны |
| `REALMS` | `softcore:ladder,hardcore:ladder` | какие режимы считать |
| `FETCH_PAGE_DELAY` | `0.3` | пауза между страницами объявлений, секунды |
| `SESSION_TTL_DAYS` | `30` | сколько хранится сессия с тайником |
| `COOKIE_SECURE` | `false` | `true`, когда сервис открыт по HTTPS |
| `ADMIN_LOGINS` | `nicweiss` | логины сайта через запятую, которым доступно ручное обновление маркета |
| `SITE_URL` | `https://blizzless.trade` | адрес сайта |
| `FRONTEND_DIR` | — | отдавать фронт с диска вместо встроенного (разработка) |

Запускайте один экземпляр: рынок держится в памяти, а обновление идёт фоновой горутиной.

## Тайник и вход

Тайник привязан к сессии браузера: кука `lp_session` (HttpOnly, SameSite=Strict). Загрузить его можно двумя способами:

- **войти через сайт.** Без «Запомнить» сервер выгружает тайник и сразу выходит из аккаунта. С «Запомнить» он
  сохраняет куки сайта, чтобы потом обновлять тайник без пароля; истёкший токен доступа продлевается через
  `/auth/refresh`, как это делает сам сайт. Пароль не сохраняется никогда;
- **загрузить файл выгрузки** (ответ `/api/be/me/stash/sources`).

**Админ** — сессия браузера, в которой прошёл вход на сайт под логином из `ADMIN_LOGINS`. Логин берётся из ответа
сайта, поэтому загрузка файла с любым именем админом не делает; «Сбросить» снимает права вместе с сессией.

Сессии лежат в `DATA_DIR/sessions` с правами `0600`, имена файлов — хэши идентификаторов. «Сбросить» удаляет
сессию и выходит из аккаунта на сайте. Пароль проходит через этот сервис, поэтому публикуйте его только за HTTPS
и с `COOKIE_SECURE=true`.

## Архитектура

```
cmd/server/                    точка входа: сборка зависимостей, HTTP-сервер, healthcheck
internal/
  domain/                      правила торговли, без ввода-вывода
    bundle/                    упорядоченный набор «код → количество» (оплата, рецепт, тайник)
    catalog/                   валюты, группы, рецепты куба, крафт слитков и сфер
    market/listing.go          объявления сайта → сделки (Trade) и действия игрока (Action)
    market/valuation.go        честные цены: робастная регрессия по сделкам
    market/relevance.go        кривая актуальности: вес сделки по её дню сезона, начало сезона по объявлениям
    market/realm_market.go     рынок режима: таблица, котировки, предложения, недооценённые лоты, вещи
    routing/                   маршрут: стоимость (обобщённый Дейкстра), бумажная и реальная цепочка;
                               стратегии фарма: маршрут с одним фармовым ресурсом без ограничения
    stash/                     тайник: разбор выгрузки, ресурсы для маршрута, оценка
  application/                 сценарии
    ports.go                   интерфейсы к сайту и хранилищам, сессия
    market_service.go          загрузка снимка, фоновое обновление, расписание
    stash_service.go           вход, обновление по запомненному входу, загрузка файла, сброс
    queries.go                 модели чтения для экранов
  infrastructure/              реализации портов
    blizzless/                 HTTP-клиент сайта: объявления, вход, продление токена, тайник
    storage/                   файлы снимка (потоковое чтение) и сессий
  interfaces/httpapi/          роуты, проверка запросов, отдача фронта
  config/                      переменные окружения
  testkit/                     синтетический рынок и фейковый сайт для тестов
frontend/                      index.html, styles.css, app.js и модули js/; встраивается в бинарь (embed.go)
deploy/                        прод: compose, Makefile сервера, конфиг nginx
```

Зависимости направлены внутрь: `interfaces → application → domain`, `infrastructure` реализует порты из
`application`. Домен не знает ни про HTTP, ни про файлы.

## API

| Метод | Путь | Что возвращает |
|---|---|---|
| GET | `/api/health` | живой ли сервис и загружен ли рынок |
| GET | `/api/meta` | режимы, справочник валют, состояние обновления |
| GET/POST | `/api/market/status`, `/api/market/refresh` | обновление рынка; запуск вручную — только админ (иначе 403) |
| GET | `/api/realms/{realm}/targets` | список целей для выбора |
| GET | `/api/realms/{realm}/target?code=` | карточка цели |
| GET | `/api/realms/{realm}/offers?code=` | живые предложения по цели |
| POST | `/api/realms/{realm}/route` | маршрут из тайника сессии |
| POST | `/api/realms/{realm}/strategy` | что дофармить (ключи, статуэтки, слитки, сферы, искры) и свой WTB по честной цене |
| GET | `/api/realms/{realm}/rates` | курс: честная цена, купить/продать, спред, кросс-курсы |
| GET | `/api/realms/{realm}/map` | узлы и рёбра карты обменов |
| GET | `/api/realms/{realm}/deals` | недооценённые объявления |
| GET | `/api/realms/{realm}/stash` | оценка тайника сессии |
| POST | `/api/stash/login`, `/api/stash/refresh`, `/api/stash/upload` | загрузка тайника |
| DELETE | `/api/stash` | сброс |

Запросы, меняющие состояние, принимаются только с `Content-Type: application/json`: так чужой сайт не может
отправить их от имени браузера.
