# Loot planner

Карта обмена для оффлайн-трейда [blizzless.trade](https://blizzless.trade): честные цены валют, курсы покупки и продажи,
недооценённые объявления и маршрут сделок из своего тайника к любой цели (руна, ключ, шард, вещь).

Один образ: бэкенд на FastAPI отдаёт API под `/api` и статический фронтенд под `/`.
Вся логика на бэкенде, фронтенд только запрашивает данные и рисует их.

## Запуск

```bash
docker compose up -d --build
```

Страница: http://localhost:8000/, документация API: http://localhost:8000/api/docs.

При первом старте снимка рынка ещё нет, и сервис сам скачивает объявления с сайта. Это 8–10 минут, страница
покажет ожидание и обновится сама. Дальше рынок обновляется по расписанию (`MARKET_REFRESH_HOURS`) и кнопкой
«Обновить маркет» в меню за шестерёнкой.

Без compose:

```bash
docker build -t loot-planner .
docker run -d -p 8000:8000 -v loot-data:/data loot-planner
```

Запускайте один процесс: рынок держится в памяти, а обновление идёт фоновым потоком этого процесса.
Памяти нужно около 320 МБ в покое и до ~800 МБ во время обновления: новый снимок разбирается, пока старый
ещё обслуживает запросы.

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `DATA_DIR` | `/data` | снимок рынка (`market/`) и сессии (`sessions/`) |
| `MARKET_REFRESH_HOURS` | `6` | период автообновления рынка, `0` — только вручную |
| `MARKET_REFRESH_COOLDOWN_MINUTES` | `10` | ручное обновление не чаще этого |
| `REALMS` | `softcore:ladder,hardcore:ladder` | какие режимы считать |
| `FETCH_PAGE_DELAY` | `0.3` | пауза между страницами объявлений, секунды |
| `SESSION_TTL_DAYS` | `30` | сколько хранится сессия с тайником |
| `COOKIE_SECURE` | `false` | `true`, когда сервис открыт по HTTPS |
| `SITE_URL` | `https://blizzless.trade` | адрес сайта |

## Тайник и вход

Тайник привязан к сессии браузера: кука `lp_session` (HttpOnly, SameSite=Strict). Загрузить его можно двумя способами:

- **войти через сайт.** Без «Запомнить» сервер выгружает тайник и сразу выходит из аккаунта. С «Запомнить» он
  сохраняет куки сайта, чтобы потом обновлять тайник без пароля. Пароль не сохраняется никогда;
- **загрузить файл выгрузки** (ответ `/api/be/me/stash/sources`).

Сессии лежат в `DATA_DIR/sessions` с правами `0600`, имена файлов — хэши идентификаторов. «Сбросить» удаляет
сессию и выходит из аккаунта на сайте.

Пароль проходит через этот сервис. Если сервис доступен не только вам, публикуйте его только за HTTPS
(reverse proxy) и с `COOKIE_SECURE=true`.

## Архитектура

```
src/loot_planner/
  domain/                 правила торговли, без ввода-вывода
    catalog.py            валюты, группы, рецепты куба, крафт слитков и сфер
    market/listing.py     объявления сайта → сделки (Trade) и действия игрока (Action)
    market/valuation.py   честные цены: робастная регрессия по сделкам
    market/realm_market.py рынок режима: таблица, котировки, предложения, недооценённые лоты, вещи
    routing/solver.py     маршрут: стоимость (обобщённый Дейкстра), бумажная и реальная цепочка
    stash/stash.py        тайник: разбор выгрузки, ресурсы для маршрута, оценка
  application/            сценарии
    ports.py              интерфейсы к сайту и хранилищам, сессия
    market_service.py     загрузка снимка, фоновое обновление, расписание
    stash_service.py      вход, обновление по запомненному входу, загрузка файла, сброс
    queries.py            модели чтения для экранов
  infrastructure/         реализации портов
    blizzless.py          HTTP-клиент сайта: объявления, вход, продление токена, тайник
    storage.py            файлы снимка и сессий
  interfaces/http/        FastAPI: роуты, схемы, сборка приложения
frontend/                 index.html, styles.css, app.js и модули js/ (без сборки)
tests/                    домен и API на синтетических данных, без сети
```

Зависимости направлены внутрь: `interfaces → application → domain`, `infrastructure` реализует порты из
`application`. Домен не знает ни про HTTP, ни про файлы.

## API

| Метод | Путь | Что возвращает |
|---|---|---|
| GET | `/api/health` | живой ли сервис и загружен ли рынок |
| GET | `/api/meta` | режимы, справочник валют, состояние обновления |
| GET/POST | `/api/market/status`, `/api/market/refresh` | обновление рынка |
| GET | `/api/realms/{realm}/targets` | список целей для выбора |
| GET | `/api/realms/{realm}/target?code=` | карточка цели |
| GET | `/api/realms/{realm}/offers?code=` | живые предложения по цели |
| POST | `/api/realms/{realm}/route` | маршрут из тайника сессии |
| GET | `/api/realms/{realm}/rates` | курс: честная цена, купить/продать, спред, кросс-курсы |
| GET | `/api/realms/{realm}/map` | узлы и рёбра карты обменов |
| GET | `/api/realms/{realm}/deals` | недооценённые объявления |
| GET | `/api/realms/{realm}/stash` | оценка тайника сессии |
| POST | `/api/stash/login`, `/api/stash/refresh`, `/api/stash/upload` | загрузка тайника |
| DELETE | `/api/stash` | сброс |

Запросы, меняющие состояние, принимаются только с `Content-Type: application/json`: так чужой сайт не может
отправить их от имени браузера.

## Разработка

```bash
uv sync
uv run pytest
MARKET_REFRESH_HOURS=0 uv run uvicorn loot_planner.interfaces.http.app:create_app --factory --reload
```

Без `DATA_DIR` данные лежат в `./data`.
